Повторяй, пиши и собирай формулы. Выводи неизвестные величины по шагам. Отдельная подборка «Динамика — к контрольной».

Скачать APK для Android

Версия 2.4.3 · Android 8.0 и новее · 1.9 МБ

  1. Скачай и открой APK на телефоне.
  2. Если Android попросит, разреши установку для браузера.
  3. Установи приложение «Формула».

Тренировки и прогресс работают без интернета. При запуске приложение проверяет обновления и предлагает установить новую версию через окно Android.

Обновляй поверх приложения, чтобы сохранить прогресс. Перенос данных с сайта: «Настройки → Скачать копию», затем «Восстановить из файла» в Android.
